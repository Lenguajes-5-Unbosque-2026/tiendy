# flujos

Pantallas exportadas de la página "📱 Diseño v3 · propuesta" del archivo de Figma Tiendy
(https://www.figma.com/design/bzbPDyDL2y6K6ED0FjBYxX/Tiendy?node-id=2048-1528).

Una carpeta por bloque de Figma (Bloque 1 a 9). El bloque 9 se llama "Perfil" en Figma, pero su
carpeta es `Mi tienda/` porque ese es el nombre oficial de la sección. Cada archivo empieza con el ID de la pantalla
(01, 16a, 41a…). Windows no permite `:` ni `?` en nombres de archivo, así que en los nombres
aparecen como `_` (por ejemplo "16a · ¿Quién atiende_").
